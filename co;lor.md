# 🎨 Styliser son texte en CSS

Voici quelques propriétés CSS pour personnaliser ton texte !

## 1. **`color` (Couleur du texte) 🎨**
   - Change la couleur du texte.
   
```css
p {
  color: blue; /* Le texte devient bleu */
}
```

## 2. **`text-align` (Alignement du texte) 🖋️**

    Définit l'alignement du texte : gauche, droite, centré, ou justifié.

```css
p {
  text-align: center; /* Le texte est centré */
}
```

## 3. **`text-decoration` (Décoration du texte) ✨**

    Ajoute des décorations comme le soulignement ou la ligne au milieu.

```css
p {
  text-decoration: underline; /* Texte souligné */
}
```

## 4. **`text-transform` (Transformation du texte) 🔡**

    Modifie le texte : majuscules, minuscules, ou capitales.

```css
p {
  text-transform: uppercase; /* Texte en majuscules */
}
```

## 5. **`text-indent` (Retrait du texte) ⬅️**

    Ajoute un retrait au début du texte, comme pour les paragraphes.

```css
p {
  text-indent: 30px; /* Retrait de 30px au début du paragraphe */
}

Résumé rapide 📚 :
| Propriété | Description | Exemple |
|---------|-------------|---------|
| color | Change la couleur du texte | `color: red;` |
| text-align | Aligne le texte | `text-align: center;` |
| text-decoration | Ajoute une décoration au texte | `text-decoration: underline;` |
| text-transform | Transforme les lettres | `text-transform: uppercase;` |
| text-indent | Ajoute un retrait au début | `text-indent: 20px;` |

Avec ces propriétés, tu peux facilement styliser ton texte en CSS ! 😎
